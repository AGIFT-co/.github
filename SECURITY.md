# セキュリティポリシー / Security Policy

## 脆弱性の報告 / Reporting a Vulnerability

AGIFT-co が公開するリポジトリ・SDK に脆弱性を発見した場合は、**公開 Issue には記載せず**、該当リポジトリの **Security タブ → 「Report a vulnerability」**（GitHub の非公開脆弱性報告）からご報告ください。

If you discover a security vulnerability in any AGIFT-co repository or SDK, please do **not** open a public issue. Instead, report it privately via the **Security tab → "Report a vulnerability"** on the affected repository.

- 報告を受領後、内容を確認のうえ対応方針をご連絡します。
- 修正の公開まで、報告内容の第三者への開示はお控えください。
- We will review your report and respond with our remediation plan. Please refrain from public disclosure until a fix is released.
